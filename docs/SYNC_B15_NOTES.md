# B15 — Native Notes Owner Recovery Center

B14 exact parent `94ed8f3506e04303fc1121d4dd72367a0377c806`. Notes Settings → Account & sync now provides a read-only recovery inspection for the currently verified owner using only the original SyncProvider status, permission, confirmed timestamp, and separate local Core request grant. The panel gives concrete signed-out, workspace-required, password-recovery, offline, failed, pending and ready actions; it never invents a cloud success or external ciphertext custody qualification.

The real native Notes BackupWorkspace and existing Supabase syncNow are the only backup/restore and cloud-writing owners. Explicit user actions can retry native sync; the inspector itself sends no request or downloads no private records. B14 device consent revocation, logout and deletion protections are preserved. No second Notes cloud engine, remote Core grants, production migrations or live data.
