# B21 original Notes cross-device continuity actions

The original Notes Account & sync view now exposes explicit, owner-initiated actions for a device switch. **Retry native sync and refresh Account devices** delegates only to original `SyncProvider.syncNow` and `refreshSessions`, with a per-owner guard before showing results. It does NOT declare success from promises alone: the user must inspect the updated actual native status, pending edits and conflicts before moving devices. Signed-out and password-recovery contexts cannot invoke the account-bound action. **Open original Backup & import for device switch** calls the existing BackupWorkspace navigation, including for guest local-only users; opening the workspace is not a verified file export. The read-only advisor classifies whether to finish Account setup, retry native sync, open the original backup, or verify an actual file. The B17 unsigned device handoff, Core revocation isolation, B19 session epoch, owner-scoped original Dexie records, and source rights are unchanged. Guest Chromium enforces Account action absence and real BackupWorkspace navigation. Independent external custody, an authenticated two-device replay and physical restoration remain NOT_TESTED.
